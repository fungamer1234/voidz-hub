# THE VOIDZ — Script Launcher

Central launcher for all VOIDZ scripts. One GUI to run them all.

## How to Use

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fungamer1234/The-voidz/main/The_Voidz_Launcher.lua", true))()
```

Press **RightShift** to toggle the hub.
